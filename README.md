## Getting started:

You're goal is to create a list that matches the famous "Jenny's Number"  in exact order and with the correct data types.
### [8, 6, 7, '-', 5, 3, 0 ,9]

You must turn in a completed slide deck showing your process and code.

3. You must not modify the starter code; however, you will need to write additional code to achieve the goal.
